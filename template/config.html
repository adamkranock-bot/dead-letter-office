Enabling this option displays modmail separately from your main inbox, with its own folders.

Select this option to enable compact mode on the inbox. Selecting this option narrows the sidebar, and collapses the card containers.

YAIR also follows Reddit Enhancement Suite's night mode. "Match system" switches with your operating system's light/dark setting.

By default, messages in a conversation are sorted from old to new. Showing the first message at the top and the last message at the bottom. This option allows you to reverse the sorting so that messages are sorted from new to old inside a message thread.

By default, new messages are polled for every minute to update the notification badge on the toolbar icon. This setting allows for changing that default.

If you switch usernames, this value will not be updated until you view your inbox.

If something has gone wrong (somehow the data in your inbox has been corrupted), you can use this option to clear out your inbox and restart from scratch.


Do note however: Reddit normally will not store more than 1000 private messages. YAIR stores messages locally, and thus will store more than 1000 messages. If you have more than a thousand messages, using this option means that you will lose your oldest messages.

If messages you know you've gotten aren't showing up in your inbox, click this button to reindex all messages without resetting the inbox. This might take a long time if you have a lot of messages!

Download every conversation YAIR has stored for this account. Reddit now keeps private messages as a read-only archive, so this is a good way to keep your own copy. The JSON export includes saved and archived flags.

YAIR was built by /u/AdhesiveCheese, building off the groundwork laid by Reddit Inbox Revamp and Reddit notifier. YAIR's design is inspired by first and foremost by RIR, but also Gmail and Reddit's Beta Modmail.

Keyboard shortcuts

j/k next/previous conversation, Enter or o open, x select, / search, Esc or u back to the list.
